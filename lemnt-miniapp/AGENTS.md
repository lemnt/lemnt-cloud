# 微信原生小程序规范

沿用根目录[统一规范](../docs/code-standards.md)，不引入React管理端的运行时或令牌。

- 运行时代码保持CommonJS、原生Page和微信API；测试使用Node内置测试器，不新增npm运行依赖。
- 页面负责交互、loading、错误和导航；请求路由、契约校验、金额显示与业务计算边界放在现有services中。
- 身份来自当前会员会话。请求发出后会员切换时拒绝使用旧响应；不得从页面输入memberId决定数据归属。
- 使用已验证的mall/app、trade/app前缀；业务开关和实际登录状态按现有流程生效，不为测试自动开启生产入口。
- 雪花ID保持十进制字符串；旧数字型ID仅接受安全整数。Long积分保持精度；金额保留服务端元文本，不在页面计算退款、尾差或权益。
- 重试复用原请求号并先查询结果，避免重复支付、领券或创建订单；服务端是订单和售后状态的权威来源。
- JS/CJS/JSON/WXSS共用管理端Prettier配置；WXML用`scripts/format_wxml.py`统一两空格缩进，不重排正文或嵌入表达式。
- 运行`npm test`、格式检查和相关页面验证。Node测试不代表WXML原生编译、微信开发者工具、支付渠道或真机验收。

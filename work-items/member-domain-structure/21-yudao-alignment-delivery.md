# 芋道业务收敛交付记录

2026-10-28。设计见 20-yudao-alignment-design.md；参考源提交 8db9153bfe6bdc03baf93b74e244a2e74477c5c4。

## 已实现

- mall：满减活动直接管理金额/件数阶梯，折扣按 SKU 管理；新增启用、关闭不可重开、关闭后删除。移除草稿发布版本、额度与请求台账。实际结算接入活动、会员折扣、券和积分，保存每行实付及积分快照。
- 商品：SPU 整体保存 SKU，保留已有主键，允许事务内交换规格；移除独立 SKU 写接口与库存调整台账。后台代会员购物、直接下单和重复加购入口移除。
- trade：统一商品售后入口，删除旧整单申请和重复退款入口；退款必须审核，退货退款须确认收货。成功退款按数量回补原已确认库存，整单退券，重复请求复用原退款及权益记录。
- member：移除额外 memberNo、后台创建与重置密码、直接经验调整；通过现有资产流水记录下单积分、支付赠送积分/经验及关单/售后回退，按原订单记录计算，避免使用当前配置重算。
- 前端与小程序调用同步；退役菜单清理保留仍使用的券查询与售后页面角色绑定，不自动授予角色。接口变化见 docs/yudao-alignment-api.md。

## 验证范围

使用生产 Mapper/XML、H2 MySQL 模式与事务代理验证活动状态、互斥、计价、行实付、SKU 更新/交换、库存退货幂等与上限；会员测试验证重复权益事件、关单及售后回退。HTTP 测试覆盖保留接口映射和服务端确定退款金额。远程边界通过测试替身，不代表供应商实测。

验证结果统一记录在 evidence/yudao-alignment-verification.json，以最终完成的构建为准，不引用重构前的旧计数。

## 数据与渠道边界

用户确认本轮先业务逻辑，支付、退款和物流渠道后续接入。没有执行真实数据库变更，没有部署、commit 或 push。旧整单折扣不能无损自动转成 SKU 折扣，旧脚本已停用；归档和升级步骤见 docs/yudao-alignment-upgrade.md。历史订单行实付保留 NULL 走历史分摊，不伪造旧成交金额。

本轮只对齐已确认业务。秒杀、拼团、砍价、分销、商城装修、客服、钱包等独立能力不包含在交付内；用户要求保留的服务边界、Redis 结算和同步下单行为继续保留。

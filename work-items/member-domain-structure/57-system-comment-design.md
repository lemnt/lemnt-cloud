# 系统评价调度设计

2026-10-29，用户指定调度器实现。沿用Spring Scheduled及现有调度启用方式，独立auto-comment.enabled显式启用，默认7天（源application.yaml），每分钟有界扫描50个已完成、未评且真实receive_time严格早于期限的订单。执行时持订单锁再次核验，历史NULL状态或收货时间不猜测，单笔失败继续下一笔。

独立私有系统保存方法固定5分/非匿名/空正文/无图片，不向HTTP暴露系统标记。商城原会员保存仍拒绝空正文。交易逐行保存后更新行状态，全部完成后记录系统34日志与finish_time；本地失败后原系统内容重试修复，远程保存不随交易回滚。与会员评价共用订单锁串行，已评不改写。任务配置关闭不影响会员评价。新增Lambda查询和状态校验，不新增表或消息/认证逻辑。测试双H2及调度回归，真实调度/网络部署另验收。不commit/push。

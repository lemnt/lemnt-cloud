# 评价图片预览和移除设计

2026-10-29，承接62上传，参考s-uploader/upload-image.vue预览和移除交互。两个评价页显示合法HTTPS缩略图，使用wx.previewImage原生预览；移除只删除当前评价附件地址，不删除OSS文件。手动地址修改及上传回填同步缩略图。

移除按已有附件地址匹配，保留剩余顺序；已提交、结果未知或上传中禁止修改，预览也校验当前会员身份，不接受事件注入任意URL。换号清理图列表。未知评价重试仍沿用原完整图片集合。无接口/数据库/权限变更。

验证两个页面的图片与提交一致、单行删除不影响其他行、未知结果冻结、预览白名单和换号清理。执行小程序全测试，真机未验证不得声称交互验收。图片存储对象生命周期不在本批范围，不commit/push。

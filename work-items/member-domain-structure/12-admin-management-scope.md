# 后台管理迁移范围

2026-10-27，按本轮用户明确范围调整优先级。

后台仅围绕商品、促销、优惠券、订单、退单、物流单、支付配置、支付单、支付退单相关管理页面迁移。商品分类、品牌、SPU、SKU及库存调整作为商品管理的组成部分。

购物车、结算预览、提交结算、代下单属于消费流程，不再按后台管理页面补齐。当前存量入口本轮未删除；删除接口、页面与权限种子需要统一核对调用方，不能仅删除 Controller 留下失效页面。本轮未更改消费端及同步下单业务流程。

| 物流单 | trade 的 shipment，已有发货、收货；已补独立物流单分页、详情和轨迹查询边界，真实轨迹供应商待接入 |

## 本轮已调整

验证：新增 HTTP 契约测试覆盖商品快照、订单字段和不存在订单；范围构建结果见 /tmp/admin-order-migration-test.log。此文件不代表九类页面已经完成迁移。

# App 活动聚合与营销规则页面交付

2026-11-01 第153批。补齐小程序营销活动聚合、限时折扣/满减送公开详情，以及满减规则的包邮、赠积分、赠券字段。营销扩展的 A03 与营销规则页面的配置侧已接通。

## App 活动聚合

- 新增 `GET /mall/app/promotion-hub/sections?limit=10`：只聚合已开启且在有效期内的秒杀、拼团、砍价、积分商城、限时折扣、满减送；积分商城无起止时间，按开启状态返回。
- 新增 `GET /mall/app/promotion-hub/discount/{id}` 与 `/reward/{id}`：公开读取进行中的规则详情；关闭或过期返回业务错误。
- 网关增加精确公开规则，活动聚合和折扣/满减详情允许匿名读取。
- 小程序新增活动中心 `pages/promotion-hub/index`：按分区展示活动，秒杀/拼团/砍价/积分商城跳转现有详情，折扣/满减跳转新规则详情页；商城首页增加“营销活动”入口。

## 营销规则页面

- `RewardRule` 增加 `freeDelivery`、`point`、`giveCouponTemplateCounts`；规则仍以 JSON 保存，旧数据自动兼容。
- 后台满减规则表单增加“赠送包邮 / 赠送积分 / 赠送优惠券（模板ID:数量）”字段，详情页展示对应权益；校验积分范围和券模板数量。
- 新增小程序规则详情页 `pages/promotion-rule/index`：展示折扣商品或满减阶梯及包邮/积分/赠券。
- 限时折扣、满减送继续在结算计价中生效金额减免；包邮、赠积分、赠券仅完成配置与展示，结算/支付后派发尚未接入。

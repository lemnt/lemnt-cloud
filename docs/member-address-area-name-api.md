# 收货地址地区全称

App地址列表、详情、默认地址三个独立响应以及后台地址列表响应新增可选areaName。原路径、分页/数组、编号和原字段不变；创建/修改请求及写响应不增加该字段。名称未知或地区服务暂不可用时为null，旧响应也可能缺失，前端保留编号显示。

名称按本地芋道AddressConvert及AreaUtils.format：省、市、区用空格连接，国内子地区不加“中国”，国外保留国家；中国节点本身仍为“中国”。实际数据复用system已经迁移的源CSV，不复制资源，不增加数据库字段。

system提供RemoteAreaService.getNames(List<Long>)只读批量RPC；启动时由已有资源构建不可变名称索引，未知编号省略。member在address域Gateway读取，列表先去重地区编号再请求一次，空列表/不存在或非本人地址不请求。详情、默认使用同一查询投影。地区RPC异常时只降级名称，保留地址；可选引用关闭provider启动检查。实际RPC超时仍使用项目已有设置。

后台会员详情地址表、小程序地址簿及结算选址显示服务返回全称；原编辑字段保持，名称不回写。订单地址RPC/订单快照未增加字段，也不按当前地区资源重写历史订单。

新增system地区RPC需部署对应provider后才有全称；provider未更新或暂不可用时维持编号展示。gateway没有引入Dubbo或新路由，auth和地址表均无变化。

验证覆盖真实system CSV格式、国家/国内/未知编号、不可变结果、member去重批量/空记录/缺失地址/降级及App三类独立Res，React和小程序旧响应兼容/非法名称/不可回写。RPC为测试替身；未执行真实跨服务Dubbo、Nacos、Redis、浏览器或微信验收。

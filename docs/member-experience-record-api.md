# 后台经验流水筛选

2026-10-30，承接经验独立表与元数据快照。GET `/member/admin/experience-records`，权限`member:experience:query`，返回继续使用统一rows/total分页及经验独立Res。详情接口和App接口不变。

|入参|规则|
|---|---|
|memberId|可选正会员编号，对应源userId|
|bizNo|业务编号精确匹配，对应源bizId，最多64字|
|experienceBizType|源数值业务类型，0同样有效，不是兼容业务码bizType|
|title|标题快照精确匹配，最多255字，不使用原因字段代替|
|startTime/endTime|`yyyy-MM-dd HH:mm:ss`，数据库本地时间，闭区间，可单边；起大于止返回400|
|pageNum/pageSize|默认1/20，最大页码1000000、页大小100|

源类型：0管理员调整、1邀新奖励、4签到奖励、5抽奖奖励、11下单奖励、12下单奖励整单取消、13下单奖励单个退款。全部枚举可查询，未接入当前写入路径的枚举没有自动补造记录。未知历史类型NULL只在不限定类型时可见；查询0不会把NULL算作管理员调整。

name/status原为未生效的通用会员入参，已从经验独立Req删除。旧原业务码bizType仍在返回值中用于兼容，不是本接口筛选项。条件在列表/总数中一致，按记录编号倒序；标题/编号不采用模糊匹配。

后台经验页提供上述筛选和日期范围，类型0按数值传递；切换记录类型重建表单并重置查询，经验条件不会发送到积分/等级/签到接口。未做部署HTTP及浏览器端到端验收；MockMvc绑定与真实H2查询分别记录在交付证据，不将前端请求测试当作上线联通。

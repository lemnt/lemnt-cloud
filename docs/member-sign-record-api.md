## 重复签到与奖励关联（2026-10-30）

按源规则，App签到当天已存在记录时返回统一业务错误409“今日已签到”，不再把旧签到当作新的成功返回。并发请求仍由会员锁与日期唯一约束保护，一次成功、另一次409，奖励只发一次；拒绝不会改变原时间和审计。

新签到的积分、经验奖励业务编号都使用实际生成的签到记录ID字符串，对应源bizId；旧日期编号的历史流水保留，不改写业务键、不补造关联。签到和两类奖励仍同事务，任一奖励失败全部回滚。当天已签判断先于规则配置查询，因此后来停用规则也不会重新奖励。

连续第几天按最大启用配置循环，昨日签到则递增，断签重置1；停用高天数规则不延长周期。缺少当前天数的启用规则时记录零奖励签到，不生成零奖励积分/经验流水；无启用配置继续明确409，未复制源空配置空指针。汇总仅当最后业务日期为今天/昨天时计连续天数，更早和未来均为0；旧业务日期兼容按102保留，未补造旧createTime。

签到规则管理仍是按day覆盖契约，与源ID创建/修改/删除不同，尚未收敛；状态仍1启用0停用。此处只对齐签到执行规则，没有宣称规则管理完整迁移。

# 后台会员关系返显

2026-10-30。GET /member-users及GET /member-users/{id}在各自独立Res追加tagIds、tagNames、levelName、groupName，权限和原rows/total或data封装不变，不增加嵌套profile对象。

|字段|来源|
|---|---|
|tagIds|既有member_tag_link的当前真实绑定，按标签编号排序|
|tagNames|当前标签记录中实际存在的名称，不从ID猜测|
|levelName|当前levelId对应的等级名称，不是历史等级变更快照|
|groupName|当前groupId对应的分组名称|

后台专用查询包装基础资料查询，按页批量读绑定，再按去重ID批量查等级、分组、标签；每张关联表最多读取一次，空页不读取。无绑定为[]，未读取的旧基础投影关系字段仍为未知NULL；元数据缺失保留已有ID，名称保持空/仅返回已读名称，不创建替代名称。资料列表与详情统一声明的关系字段，源详情当前仅补等级名称，本项目补齐其已声明的分组/标签返显供后台详情使用。

App继续使用基础查询和原独立ProfileRes，不增加上述后台字段。资料编辑仍原字段白名单，显示名称、关系编号不能经资料编辑请求被回写；分配关系保持原独立操作。元数据改名后读取当前名称，不改历史等级记录描述/快照。

React列表和详情展示返回的名称、标签；名称缺失保留真实编号提示，标签未知/无绑定/已有编号但名称缺失分开显示。字符串ID保留精度，不用元数据序号补编号。

无表/列或数据库迁移。H2关系链与改名/清空、批量调用次数及MockMvc平铺返回/App字段隔离已验证；实际部署HTTP、浏览器/微信未验收。注册IP、总积分等其他源字段仍未在本批推算，不能宣称会员完整迁移。
